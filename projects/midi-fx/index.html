MIDI FX

As a musician and programmer, I found myself building various MIDI tools to fill gaps in my workflow. Eventually, I decided to make a Swiss-army knife for MIDI and started building MIDI FX.

MIDI FX is a node editor. It is built around the idea of emergence. Simple things coming together to create something complex and interesting.

Nodes can freely manipulate MIDI messages and use Web APIs to interact with the outside world.

The project is open-source, which enables the creation of custom nodes, which are really just Svelte components.

I had the honor to present this project at ADCx India 25.

I’ve been working with my good friend Dimitri Aatos Ellinas on a successor to MIDI FX. Stay tuned for more updates!
